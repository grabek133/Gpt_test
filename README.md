# Pracownia Konstrukcji

Polskojęzyczna strona ofertowa projektanta konstrukcji i mostów.

## Uruchomienie

W katalogu repozytorium uruchom `python3 -m http.server 8000` i otwórz w przeglądarce `http://localhost:8000`. Stronę można opublikować na hostingu statycznym.

## Dane pracowni

Przed publikacją wpisz publiczny adres e-mail pracowni w stałej `contactEmail` w pliku `script.js` i dostosuj nazwę oraz zakres usług w `index.html`. Podanie adresu umożliwia przygotowanie wiadomości w programie pocztowym odwiedzającego. Przy pustym adresie formularz wyświetla treść zapytania do skopiowania.
